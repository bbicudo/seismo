# Security Policy

## Supported versions

Only the latest version on `main`, the one running on the site, receives security fixes.

## Reporting a vulnerability

Please **do not open a public issue** for security problems.

Report privately through GitHub: open the repository's **Security** tab and click **Report a vulnerability**
(private vulnerability reporting). Include:

- what the problem is and where (URL, endpoint or file),
- steps to reproduce,
- the impact you expect (for example, exposure of data that should stay private).

You can expect a first answer within a few days. Please allow reasonable time for a fix before disclosing the issue.

## Scope

In scope: the website, the public API, the admin area and the code in this repository.

Out of scope: TibiaData, tibia.com and other third-party services; denial-of-service or load testing against the
production site; findings that require access to the server.

## Privacy reports

If you find a way to obtain data the site promises not to keep or show (for example, per-character online times or
groups below the anonymity threshold), report it the same way. We treat those as security issues.

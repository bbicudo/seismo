# Code of Conduct

Seismo is a community project for Tibia players. We want it to be a friendly place for everyone, whatever
their world, guild, vocation, language or background.

## Expected behavior

- Be respectful and assume good intent.
- Keep discussions about the project: code, data, design and documentation.
- Give and accept constructive feedback gracefully.
- Respect the privacy of players. Do not post personal information about anyone, and do not use this project to
  track, expose or harass specific players.

## Unacceptable behavior

- Harassment, insults, discrimination or personal attacks.
- Sharing other people's private information.
- Spam, trolling, or in-game drama carried into issues, discussions and pull requests.

## Enforcement

Maintainers may edit or remove comments, issues, discussions and pull requests that break these rules, and may block
people who repeatedly do so. To report a problem privately, use the private reporting described in
[SECURITY.md](SECURITY.md).

This code of conduct is inspired by the [Contributor Covenant](https://www.contributor-covenant.org/).
